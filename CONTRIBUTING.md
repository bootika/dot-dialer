# Contributing to Dot Dialer

Dot Dialer is currently stabilizing its foundation. Before opening a pull request, please discuss
large user-facing features in an issue so the implementation can fit the call-lifecycle, privacy,
accessibility and testing rules of the project.

## Pull requests

1. Keep changes focused and preserve unrelated behavior.
2. Add or update automated tests for changed behavior.
3. Run the local quality gate documented in [docs/TESTING.md](docs/TESTING.md).
4. Describe what was verified and what still needs physical-device testing.
5. Preserve upstream copyright and GPL notices.

Do not include real phone numbers, contacts, call logs, credentials or other personal data in test
fixtures, screenshots, logs or issue reports.
